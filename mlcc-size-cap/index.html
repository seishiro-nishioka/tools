最大容量の表

上段: 公称の最大容量 (µF)。下段: 印加電圧での実効容量。灰色はその定格の品がなく、より高い定格の品で代用した値。「−」は量産品なし。セルにマウスを載せると根拠の品番が出る。最下行の「傾き」は、体積が10倍になると容量が何倍になるか (両対数の回帰)。

読み方
  • 横軸はサイズを外形体積の対数で並べたもの。1段上のサイズで体積はおよそ 2.4〜4.6 倍。
  • X5R/X6S は、同じ定格ならサイズを1段上げると最大容量がおよそ 2 倍 (例: 6.3 V で 0402 22 µF → 0603 47 µF → 0805 100 µF → 1206 220 µF)。
  • 同じサイズなら、定格を上げると最大容量は下がる。誘電体層を厚くする必要があるため。4 V と 6.3 V はほぼ同じ。
  • X7R/X7S は X5R/X6S より小さく、0603 以上で 1/2〜1/5 程度。0201 以下は品ぞろえが少なく、桁違いに小さい。
  • 実効容量で見ると差がさらに開く。小さいサイズの最大容量品は層が薄く、同じ電圧でも電界が強くて DC バイアスで大きく下がる。
  • 傾き (体積10倍あたりの倍率) は品ぞろえの穴に引っ張られる。0201 の 50 V (1.5 nF) のような孤立した点は、表で品番を見て判断する。
データとモデル

公称容量は、村田の汎用品 GRM シリーズで「量産中 (In Production)」の品番から、各サイズ・定格の最大値を拾ったもの ( 時点、村田の製品検索より)。各サイズで最も厚い品 (GRM022 / 033 / 155 / 188 / 21B / 31C / 32E)。NRND・量産終了予定品と、車載 (GCM)・低 ESL・3端子品は除く。他社 (TDK、Samsung など) には、これより大きい容量の品がある場合がある。

1812 (4532) の GRM は、X5R/X7R 系がすべて量産終了予定のため載せていない。1210 の 50V 品も NRND のみ。

実効容量は mlcc-dcbias と同じ考え方: 層の厚み t = √(ε0·εr·Vact / C) (Vact = 外形体積 × 有効率) を求め、電界 E = V/t を共通曲線 C/C0 = (1 + 7·(E/E50)²)−1/3 に入れる。各セルの最大容量品はサイズいっぱいに積んだ部品なので、この推定が当たりやすい。

温度特性・AC 振幅・エージング・容量許容差は含まない。
