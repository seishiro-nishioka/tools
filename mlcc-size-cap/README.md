# mlcc-size-cap — MLCC のサイズと容量の傾向

積層セラミックコンデンサ (X5R/X6S、X7R/X7S) の「サイズ × 定格電圧ごとの最大容量」をグラフと表で見るツール。DC バイアスをかけたときの実効容量も重ねて表示する。

現在のバージョン: **v2026.11.19.1**

## データ

- 村田の汎用品 GRM シリーズで「量産中 (In Production)」の品番から、各サイズ・定格の最大容量を拾ったもの (2026-11-19 に村田の製品検索で取得)。
- 各サイズで最も厚い品 (GRM022 / 033 / 155 / 188 / 21B / 31C / 32E)。X5R と X6S、X7R と X7S はまとめて扱う。
- NRND・量産終了予定品、車載 (GCM)・低 ESL・3端子品は除く。他社にはこれより大きい容量の品がある場合がある。
- その定格の品がないセルは、より高い定格の品のうち最大のもので代用し、灰色・白抜きで区別する。表のセルにマウスを載せると根拠の品番が出る。
- 1812 (4532) は、GRM の X5R/X7R 系がすべて量産終了予定のため載せていない。

## 実効容量

[mlcc-dcbias](../mlcc-dcbias/) と同じモデル。層の厚みをサイズと容量から推定し (`t = √(ε0·εr·V_act / C)`)、電界 E = V/t を共通曲線 `C/C0 = (1 + 7·(E/E50)²)^(-1/3)` に入れる。最大容量品はサイズいっぱいに積んだ部品なので、この推定が当たりやすい。印加電圧は「定格の何 %」か「固定電圧」で指定する。

## 使い方

1. 左で誘電体と表示する定格電圧を選ぶ。
2. 実効容量の条件 (印加電圧) を決める。
3. 中央上: サイズごとの最大容量 (公称 / 実効 / 両方)。中央下: 最大容量品の DC バイアス後の容量変化率。
4. 右の表: 公称の最大容量と実効容量、体積10倍あたりの容量の倍率。
5. 設定は URL に入るので、URL を共有すれば同じ表示で開ける。
