# 重ね撮りカメラ

既存の写真(基準写真)をカメラ映像に半透明で重ねて表示し、同じ角度・距離・画角で同じ対象を撮り直すためのカメラです。工事や片付けの前後比較、定点観測などに使えます。

## 特徴
- インストール不要。ブラウザで開くだけで使えます(主な対象は iPhone の Safari)
- 写真はサーバーに送信されません。処理はすべて端末内で完結します
- 基準写真の向き(EXIF の回転情報)を反映し、カメラ映像を基準写真と同じ縦横比・同じ位置で切り抜いて重ねます
- 重ね方は4種類
  - **半透明**: 濃さをスライダーで調整
  - **差分**: 重なりが合うほど黒くなる(ずれている部分が明るく浮き出る)
  - **輪郭**: 基準写真の輪郭線だけを重ねる(色・量は設定で変更)
  - **分割**: 左側に基準写真、右側にカメラ映像。境目はドラッグで移動
- 目のボタンを短く押すと重ね表示のオン/オフ、長押ししている間だけ非表示
- 2本指でつまんでズーム(端末が対応していればカメラのズーム、非対応ならデジタルズーム)。設定からカメラ(超広角・望遠など)も選べます
- 3分割グリッド表示
- **位置合わせガイド(試作)**: 基準写真とカメラ映像を照合してずれを推定し、「右を向いて 約5°」「もう1割ほど下がって」「傾きを直して(時計回り)」のように矢印と短い文字で示します。十分合うと「OK」を表示します。設定画面でオンにします(既定はオフ)
- 撮影写真には重ね画像を含めず、カメラ映像だけを高解像度で保存
- 前後比較画像(左右並び・上下並び・スライダー)の書き出し。日付などのラベルも入れられます
- 基準写真はブラウザ内に保存され、次に開いたときもそのまま使えます

## 使い方
1. 「基準写真を選ぶ」でアルバムから撮り直したい写真を選ぶ
2. 重ね表示を見ながら、端末の位置・向き・ズームを合わせる(差分や輪郭表示を使うと合わせやすい。位置合わせガイドをオンにすると、直し方を矢印と文字で表示します)
3. シャッターを押す
4. プレビュー画面の「保存・共有」→ 共有シートの「画像を保存」で写真アプリに保存
   - 「前後比較」タブで比較画像を作って保存することもできます
   - 「この写真を基準に」を押すと、撮った写真を次の基準にできます(定点観測向け)

## ホーム画面に追加
Safari の共有ボタン →「ホーム画面に追加」で、アプリのように全画面で使えます。

## メモ
- 保存される写真は基準写真と同じ縦横比に切り抜かれます。大きさはカメラ映像の解像度に依存します(iPhone の標準カメラアプリの写真より小さくなる場合があります)
- 横長の基準写真は、端末を横向きにして撮ってください。iPhone の画面縦向きロックはオフにしておく必要があります
- 基準写真を iPhone の標準カメラで撮った場合、同じ画角にするにはカメラ「背面カメラ」・ズーム 1.0× から合わせ始めるのがおすすめです(設定画面に基準写真の焦点距離が表示されます)

## 位置合わせガイドについて(試作)
- しくみ: 基準写真とカメラ映像を長辺 320px に縮小し、明るさの局所的なむらをならしてから特徴点(角)を抽出・照合し、外れ値を RANSAC で除いて「平行移動・拡大縮小・回転」を推定します。処理は Web Worker で毎秒5回ほど行い、カメラ映像の表示は止めません。外部ライブラリは使っていません
- ずれの読み方
  - 平行移動 → 向きの指示。角度は基準写真の焦点距離(EXIF の35mm換算)から計算し、情報がなければ iPhone の標準 1×(26mm)とみなします
  - 拡大縮小 → 前に出て / 下がって。カメラ1台では実際の距離が分からないため、m 数ではなく割合で示します。ズーム倍率の違いも同じように見えるので、画角(ズーム)を先に合わせてから使ってください
  - 回転 → 傾きを直して(時計回り / 反時計回り)
  - 照合点が少ない・つじつまが合わないときは指示を出さず「照合できません」と表示します
- ちらつかないよう推定値を平滑化し、指示の出る/消える境目に余裕(ヒステリシス)を持たせています。目安は向き・傾き 1.5° 以上で表示・0.7° 未満で消える、距離 4% 以上で表示・2% 未満で消える
- 限界
  - 対象が平面でない場合、横に移動したずれ(視差)は向きのずれとして表示されます(横移動の判定は未対応)
  - 朝と夜、晴れと曇りのように光の当たり方が大きく違うと、影の位置や色が変わって照合できないことがあります。全体の明るさ・色かぶりの違いには前処理である程度対応しています
  - 空・壁・水面など模様の少ない場面、木の葉や群衆など動くものが多い場面、工事の前後で見た目が大きく変わった場面は照合しにくくなります
  - 大きくずれていると照合できません(45°以上の回転、2倍以上の大きさの差は対象外)。まず重ね表示を見て大まかに合わせてから使ってください
  - 照合のため処理が増え、電池の減りが早くなり端末が温かくなることがあります

## 動作環境
iOS Safari 15 以降、Android Chrome、PC の Chrome / Edge / Safari。カメラを使うため HTTPS(GitHub Pages)で開く必要があります。共有シートに対応していない環境では JPEG としてダウンロードします。
