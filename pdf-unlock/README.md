# PDFパスワード解除

パスワードが分かっているPDFから、パスワードなしで開けるPDFを作るブラウザツールです。パスワードを推測・総当たりする機能はありません。

現在のバージョン: **v2026.11.13.1**(ツール画面のタイトル横にも表示しています。バージョンは「更新した日付.その日の何回目の更新か」の形式です)

## 特徴
- インストール不要。ブラウザで開くだけで使えます
- PDFもパスワードもサーバーに送信しません。処理はすべて端末内で完結します
- 開くときのパスワード(ユーザーパスワード)と、権限パスワード(オーナーパスワード)のどちらでも解除できます
- 印刷・コピーの制限だけが掛かったPDF(開くときにパスワードを聞かれないもの)は、パスワード空欄のままで制限を外せます
- 暗号化方式は RC4(40bit / 128bit)、AES-128、AES-256 に対応しています。日本語のパスワードも使えます
- 中身は作り直さず暗号だけを外すので、文字・画像・しおり・フォームなどはそのまま残ります
- 複数のPDFをまとめて処理でき、ZIPでまとめて保存できます

## 使い方
1. 「PDFをドロップ」からファイルを選択またはドラッグ&ドロップする(複数可)
2. パスワードを入力して「解除する」を押す(全ファイル共通のパスワードとして使われます)
3. パスワードが違ったファイルには、そのファイル用の入力欄が出るので、正しいパスワードを入れて「このファイルだけ再試行」を押す
4. 「保存」で1つずつ、「解除済みをZIPで保存」でまとめてダウンロードする。ファイル名は「元の名前_解除済み.pdf」

## 仕組み
PDF処理ライブラリ qpdf を WebAssembly 化したもの(`@neslinesli93/qpdf-wasm`)で、`qpdf --decrypt` に相当する処理をブラウザ内で実行しています。まず空のパスワードで開けるか試し(開ければ「制限だけのPDF」か「暗号化なし」)、開けなければ入力されたパスワードで解除します。
