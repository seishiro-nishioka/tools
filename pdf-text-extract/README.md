# PDFテキスト抽出

PDFに埋め込まれた文字データ(テキスト層)だけを抽出するブラウザツールです。**OCRは行いません**。スキャン画像だけで構成されたページ(文字データを持たないページ)からはテキストを抽出できません。

## 特徴
- インストール不要。ブラウザで開くだけで使えます
- PDFはサーバーに送信されません。処理はすべて端末内で完結します
- 複数のPDFをまとめてドラッグ&ドロップ可能。ファイルごとに切り替えて結果を確認できます
- テキストが検出できなかったページ(スキャン画像の可能性が高い)を自動検知し、ファイル一覧・抽出結果の両方に表示します
- ページ区切り・ページ番号の表示有無を切り替え可能
- **罫線のある表を自動検出し、本文中にCSV形式(カンマ区切り)で埋め込んで表示**(表以外の部分は通常のテキストのまま)。検出した表は一覧表示され、**表ごとにExcel形式(.xlsx)でも個別にダウンロード**できます
- 結果はクリップボードへのコピー、.txtファイルとしてのダウンロードに対応。複数ファイルを読み込んでいる場合は、まとめてZIPでダウンロードもできます
- パスワードで保護されたPDF(開くこと自体にパスワードが必要なもの)は非対応で、該当ファイルにはその旨を表示します

## 使い方
1. 左の「PDFをドロップ」からファイルを選択またはドラッグ&ドロップする(複数可)
2. ファイル一覧から確認したいファイルを選ぶと、右側に抽出結果が表示される
3. 表が検出された場合、結果の上部に一覧表示される。「⬇ Excel形式」でその表だけを.xlsxとしてダウンロードできる
4. 必要に応じて「ページ区切りを挿入」「ページ番号を表示」「検出した表をCSV形式で表示」を切り替える
5. 「コピー」でクリップボードへ、「.txtで保存」で単体ファイルとして、複数ファイルがある場合は「全ファイルをZIPで保存」でまとめてダウンロードできる

## テキストの読み取り順について
PDF内部の文字データには改行やレイアウトの情報が直接含まれていないため、このツールでは文字ごとの座標(Y座標でグループ化して行を作り、行内はX座標順に並べる)から読み取り順を推定しています。単純な縦書き文章であればほぼ正しく再現されますが、**段組みや、表として検出されなかった複雑なレイアウトのPDFでは、読み取り順が本来の文章の流れと異なる場合があります**。

文字間のスペースは、固定の間隔ではなく各文字のフォントサイズに対する相対的なしきい値で判定しています(Word等が書き出すPDFは1単語の中でも文字ごとに個別の描画命令を持つことが多く、固定しきい値だと単語の途中に余計なスペースが入ってしまうため)。

## 表の検出について
- ページを一度描画し、ピクセル単位で「長く連続した罫線」を検出することで表の格子を認識しています。**罫線(セルの区切り線)がある表のみ検出対象**で、罫線のない(余白だけで列が揃えられた)表は検出できません
- 単なる四角い枠線(1行×1列)や、写真・ノイズの多いページを誤って格子と認識しないよう、セル数が2以上かつ各セルが一定以上の大きさであることを条件にしています
- セル内で文章が複数行に折り返されている場合、CSV・Excelともにスペースで1行にまとめます(セル内改行は保持しません)
- 1ページに複数の独立した表がある場合もそれぞれ別の表として検出されます

## OCRとの違い
このツールはPDF内部に既に存在する文字データ(フォント情報付きの文字コード)をそのまま取り出すだけです。紙をスキャンしただけの画像ベースのPDFには文字データが存在しないため、抽出結果は空になります(そのページは「テキストなし」として表示されます)。そのようなPDFから文字を取り出したい場合はOCR(光学文字認識)が必要ですが、本ツールはOCR機能を持ちません。
