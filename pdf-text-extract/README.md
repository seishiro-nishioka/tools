# PDFテキスト抽出

PDFに埋め込まれた文字データ(テキスト層)だけを抽出するブラウザツールです。**OCRは行いません**。スキャン画像だけで構成されたページ(文字データを持たないページ)からはテキストを抽出できません。

## 特徴
- インストール不要。ブラウザで開くだけで使えます
- PDFはサーバーに送信されません。処理はすべて端末内で完結します
- 複数のPDFをまとめてドラッグ&ドロップ可能。ファイルごとに切り替えて結果を確認できます
- テキストが検出できなかったページ(スキャン画像の可能性が高い)を自動検知し、ファイル一覧・抽出結果の両方に表示します
- ページ区切り・ページ番号の表示有無を切り替え可能
- 結果はクリップボードへのコピー、.txtファイルとしてのダウンロードに対応。複数ファイルを読み込んでいる場合は、まとめてZIPでダウンロードもできます
- パスワードで保護されたPDF(開くこと自体にパスワードが必要なもの)は非対応で、該当ファイルにはその旨を表示します

## 使い方
1. 左の「PDFをドロップ」からファイルを選択またはドラッグ&ドロップする(複数可)
2. ファイル一覧から確認したいファイルを選ぶと、右側に抽出結果が表示される
3. 必要に応じて「ページ区切りを挿入」「ページ番号を表示」を切り替える
4. 「コピー」でクリップボードへ、「.txtで保存」で単体ファイルとして、複数ファイルがある場合は「全ファイルをZIPで保存」でまとめてダウンロードできる

## テキストの読み取り順について
PDF内部の文字データには改行やレイアウトの情報が直接含まれていないため、このツールでは文字ごとの座標(Y座標でグループ化して行を作り、行内はX座標順に並べる)から読み取り順を推定しています。単純な縦書き文章であればほぼ正しく再現されますが、**段組みや表、複雑なレイアウトのPDFでは、読み取り順が本来の文章の流れと異なる場合があります**。

## OCRとの違い
このツールはPDF内部に既に存在する文字データ(フォント情報付きの文字コード)をそのまま取り出すだけです。紙をスキャンしただけの画像ベースのPDFには文字データが存在しないため、抽出結果は空になります(そのページは「テキストなし」として表示されます)。そのようなPDFから文字を取り出したい場合はOCR(光学文字認識)が必要ですが、本ツールはOCR機能を持ちません。
