# panel-yield — 基板の取り数計算

1020mm 四方の定尺板からワークを切り出し、ワークの中に基板単品を並べたときの取り数を計算するツール。ワークサイズと基板単品の向きの組み合わせをすべて計算して一覧にし、定尺板・ワーク・基板単品を1枚の図で確認できる。

現在のバージョン: **v2026.11.11.4** (画面のタイトル横にも表示。形式は「更新した日付.その日の何回目の更新か」)

## 使い方

1. 左の欄に基板単品の寸法と間隔を入れる (捨て代・定尺板・カーフなどは規定値のままでよい)。
2. 上のタブで「候補から選ぶ」か「逆算」を選ぶ。
3. 結果の表の行をクリックすると、定尺板とワークのプレビューが切り替わる。表の「比較」にチェックを入れた行は、下にプレビューを並べて比べられる。
4. 必要なら CSV (表) や SVG / PNG (定尺板の図) で書き出す。入力値は URL に入るので、URL を共有すれば同じ条件で開ける。

データはブラウザの中だけで計算し、どこにも送信しない。

以下は仕様。

## 用語

```
定尺板 (1020×1020)
 └ ワーク × n枚   (定尺板を格子状に切り出す。回転しない)
    ├ 捨て代       (ワークの外周)
    └ 有効エリア
       └ 基板単品 × m枚 (0° / 90° を選べる)
```

- 定尺1枚あたりの取り数 = n × m
- 材料利用率 = 基板単品の面積の合計 ÷ 定尺板の面積

## 入力 (すべて mm、規定値から自由に変更可)

| 区分 | 項目 | 規定値 |
|---|---|---|
| 定尺板 | 横 × 縦 | 1020 × 1020 |
| 定尺板 | 耳 (外周の切り落とし、片側) | 5 |
| 切断 | カーフ (ワーク同士の間隔) | 3 |
| ワーク | 横の候補 | 480 / 318 / 240 / 190 |
| ワーク | 縦の候補 | 240 / 190 / 160 |
| ワーク | 捨て代 上・下 | 15 / 15 |
| ワーク | 捨て代 左・右 | 10 / 10 |
| 基板単品 | 横 × 縦 | (入力必須) |
| 基板単品 | 基板単品同士の間隔 | 2.0 (ルーター径。V カットなら 0) |

- ワークの候補は値ごとにチェックで入り切りでき、任意の値を追加できる。
- 横・縦は定尺板の向きで固定し、ワークは回転させない。

## 計算

### 1. 定尺板のワーク数

```
使える長さ = 定尺の長さ − 耳 × 2
ワーク数(1方向) = floor((使える長さ + カーフ) ÷ (ワークの長さ + カーフ))
n = 横のワーク数 × 縦のワーク数
```

規定値では、横 480→2、318→3、240→4、190→5 枚、縦 240→4、190→5、160→6 枚になる。

### 2. ワーク内の取り数

```
有効エリア = ワーク − 捨て代
取り数(1方向) = floor((有効長 + 間隔) ÷ (基板単品の長さ + 間隔))
```

基板単品の向きは次の2つを計算する。1枚のワークの中で向きは混在させない。

- **0°**: すべて入力した向きで並べる
- **90°**: すべて 90° 回転して並べる

### 3. 結果の組み合わせ

ワークの候補 (規定値で横4 × 縦3 = 12通り) × 基板単品の向き2通り = 最大24通りを、すべて表にする。

### 4. ワークサイズの逆算 (逆算モード)

基板単品のサイズから、候補の値に縛られずに適したワークサイズを求める。画面上部のタブで「候補から選ぶ」と「逆算」を切り替える。

追加の入力:

| 項目 | 規定値 |
|---|---|
| ワーク横の範囲 (最小〜最大) | 190 〜 480 |
| ワーク縦の範囲 (最小〜最大) | 160 〜 240 |
| ワーク寸法の丸め単位 | 1 |

手順 (横・縦それぞれ独立に計算し、組み合わせる):

1. 定尺板の1方向に並べるワーク数 k を 1, 2, 3, … と変える。k 枚並べられる最大のワーク長は
   `floor((使える長さ + カーフ) ÷ k − カーフ)` (丸め単位で切り捨て)。範囲外の k は除く。
2. その最大のワーク長に入る基板単品の数を、0° / 90° で求める (2. と同じ計算)。
3. その基板単品の数がちょうど収まる最小のワーク長も求める:
   `基板単品の長さ × 個数 + 間隔 × (個数 − 1) + 捨て代の合計` (丸め単位で切り上げ。範囲の最小値より小さければ最小値にする)。
4. 結果として「ワーク寸法の幅 (最小〜最大)」を示す。この幅の中ならどの寸法でも取り数は変わらない。推奨値は最小の寸法 (反りや端材が少ない)。
5. 横の k と縦の k をすべて組み合わせて取り数を計算し、一覧表にする。基板単品が入らない組み合わせは表に出さない。

例: 基板単品 50×40、間隔 2、他は規定値のとき、規定の候補で最良は 480×240 (90°) の 352 枚、逆算では 330×196 (0°、ワーク 3×5) の 360 枚。

逆算の一覧表には、次の列を加える。

- ワーク寸法の幅 (横・縦それぞれ 最小〜最大)、推奨寸法
- 規定の候補に同じ取り数になる寸法があれば、その候補 (例:「318×190 でも同数」)
## 表示

### 結果の一覧表

- 列: ワーク (横×縦)、定尺1枚あたりのワーク数、向き、1ワークあたりの取り数 (横×縦の内訳)、定尺1枚あたりの取り数、材料利用率、端材の面積
- 列の見出しをクリックして並べ替えられる。初期状態は「取り数の多い順、同数なら利用率の高い順」。
- 最大の取り数の行を強調する。取り数 0 の行は灰色にする。
- 行を選ぶとプレビューが切り替わる。複数の行を選ぶと、プレビューを横に並べて比べられる。

### プレビュー (SVG)

1枚の図に、定尺板・ワーク・基板単品をすべて描く。

- 定尺板の外形、耳、カーフ、端材 (斜線)
- 各ワークの外形と捨て代 (薄い色)
- 各ワーク内の基板単品。0° と 90° は色を分ける。
- 寸法線: 定尺板、ワーク、捨て代、基板単品
- 図の横に要約を表示: 取り数、利用率、ワーク数、1ワークあたりの取り数
- 拡大・縮小、ドラッグで移動、マウスを重ねると寸法を表示

### その他

- 入力を変えると、その場で再計算する。
- 入力値は URL に保存し、共有したり再現したりできるようにする。
- 結果の一覧表を CSV で、プレビューを SVG / PNG で書き出せる。
