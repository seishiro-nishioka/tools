# panel-yield — 基板の取り数計算

1020mm 四方の定尺板からワークを切り出し、ワークの中に基板単品を並べたときの取り数を計算するツール。基板単品のサイズから、取り数が多くなるワークサイズを逆算して一覧にし、定尺板・ワーク・基板単品を1枚の図で確認できる。

現在のバージョン: **v2026.11.11.7** (画面のタイトル横にも表示。形式は「更新した日付.その日の何回目の更新か」)

## 使い方

1. 左の欄に基板単品の寸法と間隔を入れる (捨て代・ワークの範囲・定尺板・カーフなどは規定値のままでよい)。
2. 結果の表の行をクリックすると、定尺板とワークのプレビューが切り替わる。表の「比較」にチェックを入れた行は、下にプレビューを並べて比べられる。
3. 必要なら CSV (表) や SVG / PNG (定尺板の図) で書き出す。入力値は URL に入るので、URL を共有すれば同じ条件で開ける。

データはブラウザの中だけで計算し、どこにも送信しない。

以下は仕様。

## 用語

```
定尺板 (1020×1020)
 └ ワーク × n枚   (定尺板を格子状に切り出す。回転しない)
    ├ 捨て代       (ワークの外周)
    └ 有効エリア
       └ 基板単品 × m枚 (0° / 90° を選べる。1枚のワーク内では向きを揃える)
```

- 定尺1枚あたりの取り数 = n × m
- 材料利用率 = 基板単品の面積の合計 ÷ 定尺板の面積

## 入力 (すべて mm、規定値から自由に変更可)

| 区分 | 項目 | 規定値 |
|---|---|---|
| 基板単品 | 横 × 縦 | 50 × 40 (例) |
| 基板単品 | 基板単品同士の間隔 | 2.0 (ルーター径。V カットなら 0) |
| ワーク | 捨て代 上・下 | 15 / 15 |
| ワーク | 捨て代 左・右 | 10 / 10 |
| ワーク | 横の範囲 (最小〜最大) | 190 〜 480 |
| ワーク | 縦の範囲 (最小〜最大) | 160 〜 240 |
| ワーク | 寸法の丸め単位 | 1 |
| 定尺板 | 横 × 縦 | 1020 × 1020 |
| 定尺板 | 耳 (外周の切り落とし、片側) | 5 |
| 切断 | カーフ (ワーク同士の間隔) | 3 |

横・縦は定尺板の向きで固定し、ワークは回転させない。

## 計算

### 1. 定尺板のワーク数

```
使える長さ = 定尺の長さ − 耳 × 2
ワーク数(1方向) = floor((使える長さ + カーフ) ÷ (ワークの長さ + カーフ))
n = 横のワーク数 × 縦のワーク数
```

### 2. ワーク内の取り数

```
有効エリア = ワーク − 捨て代
取り数(1方向) = floor((有効長 + 間隔) ÷ (基板単品の長さ + 間隔))
```

基板単品の向きは次の2つを計算する。1枚のワークの中で向きは混在させない。

- **0°**: すべて入力した向きで並べる
- **90°**: すべて 90° 回転して並べる

### 3. ワークサイズの逆算

横・縦それぞれについて次を求め、組み合わせる。

1. 定尺板の1方向に並べるワーク数 k を 1, 2, 3, … と変える。k 枚並べられる最大のワーク長は
   `floor((使える長さ + カーフ) ÷ k − カーフ)` (丸め単位で切り捨て)。範囲を外れる k は除き、範囲の最大値を超えるときは最大値にする。
2. その最大のワーク長に入る基板単品の数を、0° / 90° で求める (2. と同じ計算)。
3. その基板単品の数がちょうど収まる最小のワーク長も求める:
   `基板単品の長さ × 個数 + 間隔 × (個数 − 1) + 捨て代の合計` (丸め単位で切り上げ。範囲の最小値より小さければ最小値にする)。これを推奨寸法とする (反りや端材が少ない)。
4. 推奨寸法から、ワーク数と基板単品の数が変わらない最大の寸法までを「範囲」として示す。
5. 横の k と縦の k をすべて組み合わせて取り数を計算し、一覧表にする。基板単品が入らない組み合わせは表に出さない。

例: 基板単品 50×40、間隔 2、他は規定値のとき、最良は 330×196 (0°、ワーク 3×5、15枚) の 360 枚。

## 表示

画面は3カラム構成: 左に入力、中央に結果の一覧表と比較、右に要約とプレビュー。各カラムは個別にスクロールし、ページ全体は上下に動かない。幅 1100px 以下の画面では、入力・プレビュー・一覧表の順に縦に並べる。

### 結果の一覧表

- 列: 取り数/定尺、取り数/ワーク、内訳 (横×縦)、向き、推奨ワーク寸法、横の範囲、縦の範囲。利用率・ワーク数・端材は表に出さず、選んだ行の要約に表示する。
- 列の見出しをクリックして並べ替えられる。初期状態は「取り数の多い順、同数なら利用率の高い順、さらに同じならワークの小さい順」。
- 最大の取り数の行を強調する。
- 行を選ぶとプレビューが切り替わる。「比較」にチェックした行は、プレビューを並べて比べられる。

### プレビュー (SVG)

1枚の図に、定尺板・ワーク・基板単品をすべて描く。隣にワーク1枚の拡大図を寸法線付きで並べる。

- 定尺板の外形、耳、カーフ、端材 (斜線)
- 各ワークの外形と捨て代 (薄い色)
- 各ワーク内の基板単品。0° と 90° は色を分ける。
- 寸法線: 定尺板、ワーク、捨て代、基板単品
- プレビューの上に要約を表示: 取り数、利用率、ワーク寸法と範囲、ワーク数、1ワークあたりの取り数、端材
- 拡大・縮小、ドラッグで移動、マウスを重ねると寸法を表示

### その他

- 入力を変えると、その場で再計算する。
- 入力値は URL に保存し、共有したり再現したりできるようにする。
- 結果の一覧表を CSV で、プレビューを SVG / PNG で書き出せる。
