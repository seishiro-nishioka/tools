# mlcc-dcbias — MLCC の DC バイアス特性 (メーカ共通)

積層セラミックコンデンサ (Class II: X5R / X6S / X7R / X7S) の DC バイアスによる容量低下を、メーカの個別データに頼らず見積もるツール。

現在のバージョン: **v2026.11.18.1**

## 考え方

- DC バイアスで容量が下がるのは、誘電体 (チタン酸バリウム系) の誘電率が**電界**で下がるため。横軸を「電界 E = 電圧 ÷ 誘電体1層の厚み」にすると、メーカ・サイズによらずほぼ1本の曲線に乗る。
- 共通曲線は Johnson の式 `C/C0 = (1 + 7·(E/E50)²)^(-1/3)`。E50 は容量が半分になる電界で、既定値は X5R/X6S 2.2 V/µm、X7R/X7S 2.8 V/µm。ばらつきの目安として E50 ×0.7〜×1.4 を帯で表示する。
- 層の厚みはサイズと容量から推定する: `t = √(ε0·εr·V_act / C)` (V_act = 外形体積 × 有効率)。εr は X5R/X6S 3500、X7R/X7S 2500、有効率はサイズ別に 0.30 (01005) 〜 0.62 (1812)。
- 容量に対してサイズが大きい部品は推定が楽観側に出る。データシートの特性図から1点 (電圧と容量変化 %) を入れると、その点を通るように厚みを決め直す。層の厚みが分かっていれば直接指定もできる。

係数は代表的な公開特性図に合うよう決めた目安。温度特性・AC 振幅・エージング・容量許容差は含まない。

## 使い方

1. 左の欄で誘電体・サイズ・公称容量・定格電圧・印加電圧を入れる。
2. 「比較に追加」で部品を増やす (8個まで)。右の表の行をクリックするとその部品を編集できる。
3. 中央上が共通曲線 (電界に対する変化率)、中央下が部品ごとの電圧に対する容量 (変化率 % / 実効容量を切り替え)。
4. 入力値は URL に入るので、URL を共有すれば同じ条件で開ける。
