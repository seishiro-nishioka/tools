# PDF分割・結合ツール

複数のPDFをページ単位に分解し、自由に並べ替え・削除・結合して、PDF/PNG/JPGとして書き出すブラウザツールです。

## 特徴
- インストール不要。ブラウザで開くだけで使えます
- PDFはサーバーに送信されません。処理はすべて端末内で完結します
- メディアプールにファイル・フォルダを追加し、編集領域へドラッグ&ドロップ
- ドロップ位置はページとページの間を指定でき、挿入位置がハイライト表示されます
- 各ページ右上の×バッジでページ単位の削除が可能
- 編集領域内でのドラッグによるページ並べ替えに対応
- **各ページを90°単位で回転**(カード左上の↻ボタン、押すたびに90°ずつ回転)
- **ページのクロップ(余白の切り取り)**(カード右下の✂ボタン。プレビュー上をドラッグして残す範囲を選択。「編集領域の全ページに同じ比率で適用」にもチェックで対応)
- **透かし(ウォーターマーク)の追加**(「詳細設定」内。文字・大きさ・濃さを指定し、全ページへ対角線上に描画。日本語も表示可)
- **PDFのプロパティ編集**(「詳細設定」内。タイトル・作成者・件名・キーワードをPDF書き出し時に設定。空欄の項目は変更しません)。読み込んだPDFが既にタイトル等を持っている場合は、メディアプールの各ファイル名の下に既存値を表示します
- 書き出しはPDF/PNG/JPGから選択可能。画像書き出し時はzipにまとめてダウンロード(回転・クロップ・透かしは画像書き出しにも反映されます)
- PDF書き出し時に画像圧縮(弱め/標準/強め)を選べる。PDF内の写真・スキャン画像(JPEG)だけを再圧縮し、文字や図形はそのまま、見た目をほぼ保ったまま容量を減らせる

## 使い方
1. 「ファイルを選択」または「フォルダを選択」でPDFをメディアプールに読み込む(OSからのドラッグ&ドロップにも対応)
2. メディアプールのファイルを編集領域にドラッグすると、ページごとにグリッド表示される
3. 既存ページの間にドラッグすると挿入位置がハイライトされ、そこに差し込める
4. 不要なページはカード右上の×で削除、並び順はドラッグで調整
5. 必要に応じて、各ページの↻(回転)・✂(クロップ)ボタンで調整する
6. 必要に応じて、「詳細設定」を開いて透かし・PDFのプロパティ(タイトル等)を設定する
7. 書き出し形式(PDF/PNG/JPG)を選び、PDFの場合は必要なら画像圧縮の強さも選んで「書き出す」を押す

## クロップについて
- プレビュー上でのドラッグ選択は、そのページ本来の向き(回転ボタンを押す前の向き)で行います。回転と組み合わせても正しく適用されるよう、内部では別々の操作として処理しています
- 「編集領域の全ページに同じ比率で適用する」にチェックすると、選択した範囲の縦横比をもとに、サイズが異なる他のページにも同じ割合でクロップが適用されます(スキャン文書など、複数ページの余白を一括で揃えたい場合に便利です)
- クロップ範囲はPDFの表示領域(CropBox)を変更する形で適用されるため、元の画像データ自体は保持されます(非破壊)

## 画像圧縮について
- PDF内に埋め込まれたJPEG画像(写真・スキャンページなど)だけを対象に、画質を保ちつつ再圧縮します。文字・線画などのベクターデータや、埋め込みフォントは一切変更されません
- カラープロファイル付き(ICCBased、Adobe系ツールの書き出しで多い形式)のRGB/グレースケールJPEGも対象に含まれます
- 以下のような画像は、色や透過が壊れるのを避けるため圧縮の対象外としています(そのまま残ります): JPEG以外の形式で埋め込まれた画像(白黒2値スキャンのCCITT形式、PNG相当の生ビットマップなど)、CMYK/特色など特殊な色空間の画像、透過(アルファ)情報を持つ画像、極端に小さい画像
- 再圧縮した結果がかえって元より大きくなる場合は、自動的に元のデータのまま残します
- PDF全体に占める画像の割合が小さい(文字主体の)PDFでは、圧縮による削減効果は小さくなります

## 動作環境
Chrome / Edge / Safari の最新版。PDF解析・生成にpdf.js / pdf-lib、画像一括ダウンロードにJSZipを使用しています(いずれもCDN経由で読み込み)。
