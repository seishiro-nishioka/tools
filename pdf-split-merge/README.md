# PDF分割・結合ツール

複数のPDFをページ単位に分解し、自由に並べ替え・削除・結合して、PDF/PNG/JPGとして書き出すブラウザツールです。

## 特徴
- インストール不要。ブラウザで開くだけで使えます
- PDFはサーバーに送信されません。処理はすべて端末内で完結します
- メディアプールにファイル・フォルダを追加し、編集領域へドラッグ&ドロップ(各ファイル右上の×でメディアプールからの削除も可能。編集領域で使用中の場合は確認のうえ該当ページも一緒に削除されます)
- ドロップ位置はページとページの間を指定でき、挿入位置がハイライト表示されます
- 各ページ右上の×バッジでページ単位の削除が可能
- 編集領域内でのドラッグによるページ並べ替えに対応
- **各ページを90°単位で回転**(カード左上の↻ボタン、押すたびに90°ずつ回転)
- **PDFのプロパティ編集**(「書き出し条件」内の「プロパティ」欄。タイトル・作成者・件名・キーワードをPDF書き出し時に設定。空欄の項目は変更しません)。読み込んだPDFが既にタイトル等を持っている場合は、メディアプールの各ファイル名の下に既存値を表示します。**ここに入力した内容はPDFファイル自体に埋め込まれ、ファイルを受け取った人なら誰でも「ドキュメントのプロパティ」等から閲覧できます**(本文のように隠れているわけではありません)。本名・所属・社内限定の情報など、公開したくない内容は入力しないようご注意ください
- 書き出しはPDF/PNG/JPGから選択可能。画像書き出し時はzipにまとめてダウンロード(回転は画像書き出しにも反映されます)
- PDF書き出し時に画像圧縮(弱め/標準/強め)を選べる。PDF内の写真・スキャン画像(JPEG)だけを再圧縮し、文字や図形はそのまま、見た目をほぼ保ったまま容量を減らせる
- **編集・印刷のみ制限された暗号化PDF(閲覧パスワードは不要なもの)を自動検知して復号**。読み込み時にメディアプールへその旨を表示し、PDF書き出し時に制限を解除します(本当に閲覧パスワードが必要なPDFは非対応です)
- **透かしの文字を検出して消す**(「書き出し条件」内の「透かし文字の削除」欄。自動検出した候補から選んだ文字列を検出し、白い矩形で覆って見えなくします。詳細は下記「透かしの削除について」を参照)
- ヘッダーの「📄 ライセンス」ボタンから、使用しているライブラリ(pdf.js / pdf-lib / JSZip / Webフォント)のライセンス種別と、個人・商用利用の可否を確認できます

(クロップ・透かしの追加・署名/スタンプ機能は実装済みですが、現在UI上では一時的に無効化(非表示)にしています)

## 使い方
1. 「ファイルを選択」または「フォルダを選択」でPDFをメディアプールに読み込む(OSからのドラッグ&ドロップにも対応)
2. メディアプールのファイルを編集領域にドラッグすると、ページごとにグリッド表示される
3. 既存ページの間にドラッグすると挿入位置がハイライトされ、そこに差し込める
4. 不要なページはカード右上の×で削除、並び順はドラッグで調整
5. 必要に応じて、各ページの↻(回転)ボタンで調整する
6. 必要に応じて、「書き出し条件」内の「プロパティ」欄でPDFのプロパティ(タイトル等)を設定する
7. 「書き出し条件」でファイル形式(PDF/PNG/JPG)を選び、PDFの場合は必要なら画像圧縮の強さも選んで「書き出す」を押す

## クロップについて
- プレビュー上でのドラッグ選択は、そのページ本来の向き(回転ボタンを押す前の向き)で行います。回転と組み合わせても正しく適用されるよう、内部では別々の操作として処理しています
- 「編集領域の全ページに同じ比率で適用する」にチェックすると、選択した範囲の縦横比をもとに、サイズが異なる他のページにも同じ割合でクロップが適用されます(スキャン文書など、複数ページの余白を一括で揃えたい場合に便利です)
- クロップ範囲はPDFの表示領域(CropBox)を変更する形で適用されるため、元の画像データ自体は保持されます(非破壊)

## 署名・スタンプについて
- 「詳細設定」で登録した画像は、ページをまたいで繰り返し使い回せます(例: 同じ印影画像を複数ページに配置)
- 配置の座標系はクロップと同じく「ページ本来の向き」基準です。回転したページに配置した場合も、書き出し結果では正しい位置に表示されます
- 配置した画像はPDFの内容として直接描画されるため、書き出し後に動かしたり削除したりはできません(配置をやり直したい場合は、編集領域に残っている間に🖋ボタンから再編集してください)

## 画像圧縮について
- PDF内に埋め込まれたJPEG画像(写真・スキャンページなど)だけを対象に、画質を保ちつつ再圧縮します。文字・線画などのベクターデータや、埋め込みフォントは一切変更されません
- カラープロファイル付き(ICCBased、Adobe系ツールの書き出しで多い形式)のRGB/グレースケールJPEGも対象に含まれます
- 以下のような画像は、色や透過が壊れるのを避けるため圧縮の対象外としています(そのまま残ります): JPEG以外の形式で埋め込まれた画像(白黒2値スキャンのCCITT形式、PNG相当の生ビットマップなど)、CMYK/特色など特殊な色空間の画像、透過(アルファ)情報を持つ画像、極端に小さい画像
- 再圧縮した結果がかえって元より大きくなる場合は、自動的に元のデータのまま残します
- PDF全体に占める画像の割合が小さい(文字主体の)PDFでは、圧縮による削減効果は小さくなります

## 透かしの削除について
- 対象は**文字(テキスト)の透かし**のみです。「書き出し条件」の「透かし文字の削除」で「透かしの文字を検出して消す」にチェックを入れ、「🔍 候補を自動検出」を押すと使えます
- **自動検出は、透かしらしい文字列を提案する機能です**。編集領域の全ページを走査し、各テキストの「回転角度」「文字色の薄さ(明るいグレー等)」「不透明度」「複数ページへの同一内容の繰り返し出現」を組み合わせてスコアリングし、候補一覧をチェックボックス付きで表示します(可能性が高いものには自動でチェックが入ります)。あくまで候補の提示までで、**実際に削除するかどうかは必ずチェックボックスで選択してください**。見出しや繰り返しのフッターなど、透かしでない文字列が候補に挙がることもあります(自動削除はしません)
- **PDFとして書き出す場合は「真の削除」です**。PDF内部のコンテンツストリーム(描画命令)から該当する文字の描画命令そのものを取り除くため、白で覆うのではなく、PDF内部のデータとしても文字情報が無くなります。コピー&ペーストやテキスト抽出をしても元の文字は出てきません
- **PNG/JPG画像として書き出す場合は白い矩形で覆う方式**になります。出力がラスタ画像(文字データを持たない)になるため、「描画命令を取り除く」という操作自体が意味を持たないためです
- 回転・半透明の対角線上の透かしにも対応しています
- 画像だけで構成された透かし(スキャン画像に焼き込まれたものなど、文字データを持たないもの)は検出できません
- PDFの構造が複雑で安全に削除できない箇所があった場合は、書き出し完了時のメッセージでその旨(検出数に対する削除数)を表示し、削除できなかった箇所は元のまま残します(壊れる可能性があるものを無理に書き換えることはしません)

## 暗号化PDFについて
- 「編集・印刷だけ制限されており、閲覧パスワードは不要(空)」なPDF(請求書・契約書などでよく見られるタイプ)は、読み込み時に自動で検知し、メディアプールにその旨を表示します。PDFとして書き出す際に、PDF標準セキュリティハンドラ(RC4 40/128bit、AES-128、AES-256に対応)をブラウザ内で復号して制限を解除します
- これは、暗号化PDFをそのまま書き出すと、ページ内容(文字・画像の描画命令)が暗号化されたバイト列のままコピーされてしまい、開いても白紙ページになる不具合への対応です(書き出すまではpdf.jsが正しく復号してプレビュー表示するため気づきにくい問題でした)
- **本当に閲覧パスワードが必要なPDF**(開くこと自体にパスワード入力が要るもの)は非対応です。読み込み時点でエラーになります
- 圧縮された相互参照ストリーム+オブジェクトストリーム(PDF 1.5以降の一部のツールが出力する形式)と組み合わされた暗号化PDFは、読み込みの時点で失敗する場合があります
