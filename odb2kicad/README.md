# ODB++ → KiCad 変換

CAD が出力した ODB++ の基板データを、KiCad で閲覧できる `.kicad_pcb` に変換するツールです。KiCad 9 / 10 で開けます。

## 特徴
- インストール不要。ブラウザで開くだけで使えます
- データはサーバーに送信されません。処理はすべてブラウザ内で完結します
- 入力: ODB++ の zip / tgz / tar、またはフォルダ (`.Z` で圧縮された層ファイルにも対応)
- 出力の中身
  - 各層の図形 → 塗りつぶしポリゴン (正極性・負極性を合成し、穴付きの形は分割)
  - 外形 (profile) → Edge.Cuts
  - 部品 → フットプリント (リファレンスと値を Fab 層に表示。パッドは銅箔の形をそのまま写し、ネット名付き)
  - 部品ピンと一致する穴 → スルーホールパッド (長穴にも対応)、残りの丸穴 → ビア、銅箔のない穴 → 穴だけのパッド
- 面付け (STEP-REPEAT) を展開します (入れ子・回転・ミラーに対応)。各コピーの部品のリファレンスとネット名には `_P1` `_P2` … の接尾辞が付き、コピーごとに別ネットになります。面付けのステップがあれば既定でそれを選びます (単品のステップも選べます)
- 層の割り当てはマトリクスの種類と面から自動で決めます (信号層 → F.Cu / In*.Cu / B.Cu、ソルダーマスク → *.Mask、メタルマスク → *.Paste、シルク → *.SilkS)。補助層 (MISC など) は User.1… に元の層名を付けて入れ、画面で変更・除外できます
- 変換後に表 / 裏のプレビューを表示し、未対応の要素は警告に出します

## 使い方
1. ODB++ のファイル (zip / tgz) かフォルダをドロップ、または「ファイルを選ぶ」「フォルダを選ぶ」で読み込む
2. 自動で変換され、結果 (部品・パッド・ネット・ビアの数) とプレビューが出る
3. 必要なら層の割り当てを変えて「割り当てを反映して再変換」
4. 「.kicad_pcb をダウンロード」で保存し、KiCad で開く

## 制限
- 閲覧用です。銅箔は図形 (ポリゴン) として入るため、KiCad の DRC や配線編集には向きません
- 文字 (T レコード)・バーコードは描画しません。熱抵抗シンボル以外の特殊な標準シンボル (moire など) は警告を出して省きます
- 表裏反転 (FLIP) 指定の面付けは、反転せずに配置します (警告を表示)
- パッドの基準点 (ピン位置) に銅箔がない形では、KiCad が基準点に置く小さな丸 (φ0.05mm) が銅箔からはみ出して見えます
- 部品の回転はフットプリントの角度には反映せず、パッドを基板上の位置・向きのまま配置します
