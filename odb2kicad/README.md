# ODB++ → KiCad 変換

CAD が出力した ODB++ の基板データを、KiCad で閲覧できる `.kicad_pcb` に変換するツールです。KiCad 9 / 10 で開けます。

現在のバージョン: **v2026.11.10.7**(ツール画面のタイトル横にも表示しています。バージョンは「更新した日付.その日の何回目の更新か」の形式で、例えば v2026.11.10.6 は 2026年11月10日の6回目の更新です)

## 特徴
- インストール不要。ブラウザで開くだけで使えます
- データはサーバーに送信されません。処理はすべてブラウザ内で完結します
- 入力: ODB++ の zip / tgz / tar、またはフォルダ (`.Z` で圧縮された層ファイルにも対応)
- 出力の中身
  - 各層の図形 → 塗りつぶしポリゴン (正極性・負極性を合成し、穴付きの形は分割)
  - 外形 (profile) → Edge.Cuts
  - 部品 → フットプリント (リファレンスと値を Fab 層に表示。パッドは銅箔の形をそのまま写し、ネット名付き)
  - 部品ピンと一致する穴 → スルーホールパッド (長穴にも対応)、残りの丸穴 → ビア、銅箔のない穴 → 穴だけのパッド
- 面付け (STEP-REPEAT) を展開します (入れ子・回転・ミラーに対応)。各コピーの部品のリファレンスとネット名には `_P1` `_P2` … の接尾辞が付き、コピーごとに別ネットになります。面付けのステップがあれば既定でそれを選びます (単品のステップも選べます)
- 層の割り当てはマトリクスの種類と面から自動で決めます (信号層 → F.Cu / In*.Cu / B.Cu、ソルダーマスク → *.Mask、メタルマスク → *.Paste、シルク → *.SilkS)。補助層 (MISC など、KiCad の User 層に入る層) は既定で「除外」にします。KiCad で使わない文字や図形が多く、変換もファイルも重くなるためです。必要な層は、割り当てで User.2 などを選んで「割り当てを反映して再変換」を押すと、元の層名を付けて入ります。除外した層は解析もしません
- User.1 は V カット用に空けておきます (JLCPCB 向けの製造データ出力プラグインが V カットの指定に User.1 を使うため)。自動では何も入れず、層の一覧には常に定義しておくので、KiCad 上ですぐ V カットの線を描けます。ODB++ 側に V カットの層があれば、割り当てで User.1 を選んで入れることもできます
- 変換後に表 / 裏のプレビューを表示し、未対応の要素は警告に出します。層の色は KiCad の既定の配色に合わせています (User 層は層ごとに色分け)
- 層の割り当て表とプレビューが連動します
  - 行にカーソルを乗せる (スマホではタップ) と、その層だけを強調し、他の層は薄く表示します。タップ / クリックで強調を固定し、もう一度で解除します
  - 各行の目のアイコンで、プレビューに出す層を個別に切り替えられます。変換に含めるかどうか (KiCad 層の選択・除外) とは別の操作です
  - 除外中の層も、強調したり目をオンにしたりすると、その場で解析して表示します (破線の輪郭と半透明の塗りで、変換に含まれないことが分かる見た目)。解析は表示を求められた層だけで、結果は使い回します
  - 割り当てや除外を変えると、プレビューはすぐに変わります。結果の数と .kicad_pcb は「割り当てを反映して再変換」か、ダウンロードのときに作り直します

## 使い方
1. ODB++ のファイル (zip / tgz) かフォルダをドロップ、または「ファイルを選ぶ」「フォルダを選ぶ」で読み込む
2. 自動で変換され、結果 (部品・パッド・ネット・ビアの数) とプレビューが出る
3. 必要なら、プレビューで層の中身を確かめながら層の割り当てを変える (目のアイコンで表示を切り替え、行にカーソルを乗せる / タップで強調)
4. 「.kicad_pcb をダウンロード」で保存し、KiCad で開く。ファイル名は「ジョブ名_ステップ名.kicad_pcb」で、面付けと単品を取り違えないようステップ名が入ります

## 制限
- 閲覧用です。銅箔は図形 (ポリゴン) として入るため、KiCad の DRC や配線編集には向きません
- 文字 (T レコード)・バーコードは描画しません。熱抵抗シンボル以外の特殊な標準シンボル (moire など) は警告を出して省きます
- 表裏反転 (FLIP) 指定の面付けは、反転せずに配置します (警告を表示)
- パッドの基準点 (ピン位置) に銅箔がない形では、KiCad が基準点に置く小さな丸 (φ0.05mm) が銅箔からはみ出して見えます
- 部品の回転はフットプリントの角度には反映せず、パッドを基板上の位置・向きのまま配置します
