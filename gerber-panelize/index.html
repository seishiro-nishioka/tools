    「自動」はレールに向かう辺に1本 (左右レールなら左右の辺、上下レールなら上下の辺)。本数は基板の外接矩形の辺を等分した位置に置きます (KiKit の fixed タブと同じ)。

    穴径 / 中心間 / mm
    外側へのずれmm (穴の中心と基板端の距離)
    線の延長mm
    内角 Rmm
    タブを置かない方がよい場所 (規格 5章)
    • 端までピンや穴が並んでいる辺: マウスバイトと穴が干渉する。
    • コネクタの差し込み口の前: 切り離した後の出っ張りでプラグが入りにくくなる。避けられないなら、やすりで仕上げる前提を基板の README に書く。
    • アンテナの禁止領域: キープアウトに穴が入る。マウスバイトを外側に置く標準値なら、基板端までのキープアウトには掛からない。
    • 製品と捨て板のすき間が 2mm 未満になる場所: 内角 R の処理ですき間が埋まり、製品が捨て板とくっつく。L 字などでタブが長い棒になると起きやすい (切り離しチェックで NG になる)。
    • 1辺1本で支えるなら反対側の辺にも必ず1本置き、偏らないようにする。L 字や凹みのある基板は、タブが製品の辺に短く届く向きを選ぶ。

    タイトル (レールのシルク)

    文字の高さmm、線幅mm

    {name} 基板名、{rows} 行、{cols} 列、{date} 今日の日付。空欄なら付けません。レールに入らないとき (1文字 1.3mm + 両端 12mm で見積もり) は省きます。英小文字は大文字の字形で描きます。

    切り離しチェック

    案を選ぶとチェックします

      マウスバイトの線でパネルを折ったとき、各基板が基板単品と同じ形 (面積の差 0.5% 以内) の1片として外れ、折る前のパネルが1枚につながっていることを確かめます (embedded-projects の scripts/check_panel.py と同じ考え方)。DRC はしないので、KiCad で確認してください。

        ダウンロード

        KiCad での確認のしかた
        • zip を展開し、KiCad の ガーバービューア (gerbview) で「ファイル → ガーバーとドリルのファイルを開く」から全ファイルを開く。
        • 外形 (Edge_Cuts)、マウスバイトの穴 (NPTH)、タブの位置、タイトル、フィデューシャルを目で確かめる。
        • DRC をするなら、gerbview の「ファイル → PCB エディターへエクスポート」で .kicad_pcb にし、PCB エディターで開く (ネット情報はないので、クリアランスの目安として使う)。
        • 部品の位置 (CPL) は、JLCPCB の発注画面のプレビューで確認する。
