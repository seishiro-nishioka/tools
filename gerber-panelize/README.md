# gerber-panelize — ガーバーの面付け

KiCad で出した基板単品のガーバーとドリルから、JLCPCB に出す面付けパネルのガーバー一式を作るツール。KiKit も KiCad も使わず、ブラウザだけで動く。部品の実装を頼むときは、パネルに合わせてずらした CPL (部品座標) も作れる。

現在のバージョン: **v2026.11.22.1** (画面のタイトル横にも表示。形式は「更新した日付.その日の何回目の更新か」)

データはブラウザの中だけで処理し、どこにも送信しない。

面付けの標準値は、embedded-projects の社内規格 `libraries/design_notes/panelization.md` (根拠は `libraries/jlcpcb_reference/panelization.md`) と `scripts/panelize.sh` (KiKit) に合わせてある。規格の値を変えたら、このツールの既定値 (`DEFAULTS`) も合わせる。

## 使い方

1. KiCad の「製造用ファイル出力」でガーバー (Edge.Cuts を含む) とドリルファイル (PTH / NPTH を別ファイルにするのがおすすめ) を出し、zip のまま、または複数ファイルを左上の欄にドロップする。
   - 実装も頼むなら、CPL (`kicad-cli pcb export pos --format csv` などの位置ファイル) と BOM の csv も一緒にドロップする。CPL はガーバーと同じ原点で出す (どちらも既定の絶対座標、またはどちらもドリル/補助原点)。
2. 中央上の「面付けの案」に、レールの向き (上下 / 左右) × 基板の回転 (0° / 90°) × 行×列 のうち 100×100mm に収まるものが、枚数の多い順に並ぶ。最初は、切り離しチェックが OK の案のうち枚数が最も多いものが選ばれる。行をクリック (または ↑↓ キー) で切り替える。
3. 中央下のプレビューで、全レイヤー (銅・シルク・マスク・ペースト・穴・外形) を重ねて確認する。チェックボックスで表示を切り替え、ホイールで拡大縮小、ドラッグで移動。寸法線はパネル全体・基板単品・基板間。
4. 右の「切り離しチェック」が **OK** であることを確かめる。**NG のパネルは発注しない** (下の「切り離しチェック」)。
5. 「ガーバー zip」をダウンロードして JLCPCB に入稿する。CPL・BOM・面付け設定 JSON も必要に応じてダウンロードする。
6. KiCad で確認する (下の「KiCad での確認」)。

条件 (左下) は画面で変えられる。「標準値に戻す」で規格の値に戻る。

## 面付けの規格 (既定値)

| 項目 | 既定値 | 画面の項目 |
|---|---|---|
| パネル寸法 | 100×100mm 以内の案だけを一覧に出す | 最大寸法 |
| レール | 上下か左右の一方の対だけ。幅 5mm、基板とのすき間 2mm。長さは基板の並びと同じ | レールの向き、レール幅、レールとのすき間 |
| 基板間 | 2mm | 基板間 |
| タブ | 幅 5mm。本数は「左右の辺」「上下の辺」ごと (KiKit の `hcount` / `vcount`) | タブ幅、左右の辺の本数、上下の辺の本数 |
| タブの本数「自動」 | レールに向かう辺に1本 (左右レールなら左右の辺、上下レールなら上下の辺) | |
| マウスバイト | 穴径 0.6mm、中心間 0.85mm 以下 (線の長さを等分)、穴の中心を基板端から 0.3mm 外側 (穴の縁が外形に接する)、線をタブの両端から 0.5mm 延長 | 穴径 / 中心間、外側へのずれ、線の延長 |
| 内角 R | 1mm (ミル加工で角が丸くなるのを反映。すき間が 2mm 未満の所は埋まる) | 内角 R |
| ツーリングホール | パネルの短辺が 70mm 以上のときだけ。2mm NPTH を4隅、レール幅の中心。上下レールなら端から横 5mm・縦 2.5mm、左右レールなら横 2.5mm・縦 5mm | 付ける条件、ツーリング穴径 |
| フィデューシャル | 同じく 70mm 以上のときだけ。銅 1mm / マスク開口 2mm を表裏に3点 (左上・右上・左下)。上下レールならパネルの端から横 7mm・縦 3.85mm、左右レールなら横 3.85mm・縦 7mm | フィデューシャル |
| タイトル | レールの中央 (左右レールなら左レールに縦書き)、文字の高さ 1.5mm、線幅 0.25mm。既定の文字は `{name} {rows}x{cols}`。1文字 1.3mm + 両端 12mm で見積もってレールに入らなければ省く | タイトル |

70×70mm 未満のパネルは JLCPCB の Economic PCBA 向け (ツーリングホールとフィデューシャルは不要) として作る。一覧の「実装」列に Standard 可 / Economic を出す。

タブを置かない方がよい場所 (規格 5章) は、画面の「タブを置かない方がよい場所」に書いてある。

## 面付けのしかた (KiKit との対応)

- 基板単品の外形は Edge.Cuts のガーバーの線と円弧をつないで作る。閉じていない線は外形に使わない (画面に警告)。
- 基板は行×列の格子に並べる。回転は 90° (反時計回り) だけ。
- タブは KiKit の `fixed` タブと同じく、基板の外接矩形の辺を (本数 + 1) 等分した位置に置く。タブの幅の帯を、隣の基板との中間 (レールならレールの内側の辺) から基板の方へ伸ばし、基板にぶつかるまでの部分をタブにする。L 字や凹みのある基板では、タブが凹みの奥まで伸びることがある。
- 辺の長さに本数が入りきらないときは、KiKit と同じ式で本数を減らす。
- マウスバイトは、タブと基板が接する外形の線を両端で 0.5mm 延長し、基板の外側へ 0.3mm ずらした線の上に、等間隔 (中心間 0.85mm 以下) に置く。基板のない所 (すき間) に落ちる穴は置かない。
- 内角 R は、パネル全体を R だけ太らせてから細らせる処理 (KiKit の `millradius` と同じ)。ただし、基板単品の中の穴 (切り抜き) は元の形のまま残す。
- 外形 (Edge_Cuts) は、レール・タブ・基板を合わせたパネルの外形だけを出力する。形の計算は細かい線分 (誤差 0.002mm 以下) で行い、書き出すときに、1つの円の上に並ぶ線分 (基板単品の円弧、内角 R) を円弧 (G02/G03) にまとめ直す。CB003 4×2 で線分だけの 33KB が 5.6KB になる。

embedded-projects の CB003 (4×2、左右レール)、CB008 (1枚、左右レール)、KB02 (L 字、1枚、上下レール) で、`scripts/panelize.sh` が作ったパネルと、パネル寸法・マウスバイトとツーリングホールの数と位置 (0.01mm 以内)・外形の面積・切り離した後の片の数が一致することを確かめた。出力は KiCad 10 のガーバービューアで開けることも確かめた (2026-11-20)。

## 切り離しチェック

embedded-projects の `scripts/check_panel.py` と同じ考え方で、案ごとに自動で確かめる (一覧の「切り離し」列と、右上の表示)。

1. 折る前: パネル (内角 R の後) が1枚につながっていること。分かれていれば、タブのない浮いた基板がある。
2. 折った後: マウスバイトの穴を結んだ線 (両端を 1.5mm 延長し、穴径 + 0.02mm の幅) でパネルを切り、出てきた片のうち各基板に重なるものが **1片だけ** で、その面積が基板単品と **0.5% 以内** で同じこと。
   - 片が大きい: 基板が捨て板とくっついたまま (すき間が 2mm 未満で内角 R で埋まった、または切られないタブがある)。KB02 を左右レールにしたときに起きる。
   - 片が複数: 基板が割れる。

NG の基板はプレビューで赤く表示し、ガーバー zip のボタンも赤くなる (ダウンロードすると確認が出る)。

## 出力

| ファイル | 内容 |
|---|---|
| `<名前>-panel-<行>x<列>.zip` | パネルのガーバーとドリル。ファイル名は入力と同じ (KiCad の名前のまま)。JLCPCB にそのまま入稿できる |
| `<名前>-panel-<行>x<列>-cpl.csv` | パネルの座標にずらした CPL。列は `Designator,Val,Package,Mid X,Mid Y,Rotation,Layer`。部品番号は枚数分だけ重複したまま (KiKit の `fab jlcpcb` と同じ)。90° 回した案では Rotation に 90 を足す |
| `<名前>-panel-<行>x<列>-bom.csv` | 入力した BOM をそのまま (部品番号を変えないので BOM も変わらない) |
| `<名前>-panel-<行>x<列>.json` | 面付け設定。左の「設定 JSON を読み込む」で読むと、同じ条件と案を再現する |

ガーバーの中身:

- 各レイヤーは、基板単品の図形を枚数分ずらして (回転した案では回して) 並べたもの。アパーチャ (パッドの形) は回転に合わせて書き換える (矩形・長円は縦横を入れ替え、多角形とマクロは回転角に 90 を足す)。単位とアパーチャ番号は入力のまま、座標の書式は 4.6 (mm)。
- Edge_Cuts: パネルの外形 (線幅 0.05mm、直線と円弧)。
- 銅 (表・裏): フィデューシャル (銅 1mm)。マスク (表・裏): フィデューシャルの開口 2mm。
- 表のシルク: タイトル。英小文字は大文字の字形で描く (数字・英字・`-_.+/:()#=,` に対応)。
- NPTH のドリル: マウスバイトとツーリングホールを追加する。NPTH のファイルがなければ `<名前>-NPTH.drl` を新しく作る。
- ジョブファイル (`.gbrjob`) があれば、基板寸法をパネルの寸法に書き換える。

読めない Gerber: 相対座標、ステップ&リピート (`%SR`)、アパーチャブロック (`%AB`)、層の回転・鏡像・拡大 (`%LR` `%LM` `%LS`、恒等以外)。KiCad の出力は使わないので、ふつうは問題にならない。

## KiCad での確認

DRC はこのツールではしない。出力したガーバーを KiCad に取り込んで確認する。

1. zip を展開し、KiCad の**ガーバービューア** (gerbview) で「ファイル → ガーバーとドリルのファイルを開く」から全ファイルを開く。
2. 外形 (Edge_Cuts)、マウスバイトの穴 (NPTH)、タブの位置、タイトル、フィデューシャルとツーリングホールの位置を目で確かめる。タブがコネクタ・ピン・アンテナにかかっていないかも見る (規格 2章 7)。
3. DRC をするなら、gerbview の「ファイル → PCB エディターへエクスポート」で `.kicad_pcb` にして PCB エディターで開く。ネット情報はないので、クリアランスの目安として使う。KiKit で作ったパネルと同じく、面付けで増えたエラーがないことを基板単品と比べる。
4. CPL は、JLCPCB の発注画面の部品配置のプレビューで位置と向きを確かめる。

hawk の KiCad 10 (Flatpak) で開くときは、Flatpak の中からはホームと `/media` しか見えないので、zip はホームの下に展開する。

## 発注まで

embedded-projects の規格 (1章) のとおり、発注したガーバーは `boards/<基板>/orders/<日付>_<業者>_<種類>/` に保存し、`order.md` に枚数・価格・面付けの種類・元のコミットを書く。面付け設定 JSON も一緒に入れておくと、同じパネルを作り直せる。
