# ズームPiPメーカー

動画の一部を枠で囲み、拡大映像をピクチャインピクチャで重ねて書き出すブラウザツールです。

## 特徴
- インストール不要。ブラウザで開くだけで使えます（PC・スマホ対応）
- 動画はサーバーに送信されません。処理はすべて端末内で完結します
- 拡大範囲・拡大画面はドラッグで調整
- 枠の色・太さ、拡大画面の枠や影、元範囲と拡大画面をつなぐ線を設定可能
- 書き出し範囲の指定、1× / 2× / 4× の倍速書き出し、音声なし書き出しに対応

## 使い方
1. 動画ファイルを読み込む
2. 拡大したい場所をドラッグで囲む
3. 拡大画面をドラッグで好きな位置へ移動（右下の角で大きさを変更）
4. 「動画を書き出す」を押す

書き出しは再生しながら録画する方式のため、動画の長さ÷速度ぶんの時間がかかります。完了までタブを表示したままにしてください。

## 動作環境
Chrome / Edge / Safari の最新版。保存形式はブラウザにより MP4 または WebM になります。
