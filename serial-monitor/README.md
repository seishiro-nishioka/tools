# シリアル通信モニター

マイコンなどのシリアルポートをブラウザから直接読み書きするツールです。Web Serial APIを使い、ポート・ボーレートなどを指定して接続します。

## 特徴
- インストール不要。ブラウザで開くだけで使えます
- 通信内容はサーバーに送信されません。処理はすべて端末内で完結します
- ボーレート(300〜2,000,000、カスタム値も可)、データビット・ストップビット・パリティ・フロー制御を指定可能
- 一度許可したポートは次回から一覧から選んで再接続できます(毎回のポート選択ダイアログ不要)
- 受信ログはテキスト/HEXの2形式で表示切替、タイムスタンプ表示にも対応
- ログはテキストファイルとしてダウンロード可能
- 改行コード(なし/LF/CR/CRLF)を選んでテキストを送信可能(マイコンへのコマンド送信・AT コマンド確認などに)

## 使い方
1. ボーレートなどを設定し、「ポートを選択して接続」を押す
2. ブラウザのダイアログでシリアルポートを選択する(USB-UART変換アダプタや、ESP32/RP2040などのネイティブUSBシリアルを認識します)
3. 受信データがターミナル欄に表示される。テキスト/HEXの切替、タイムスタンプ表示、自動スクロールのON/OFFが可能
4. 必要に応じて下部の入力欄からコマンドを送信する
5. ログは「ダウンロード」でテキストファイルとして保存、「クリア」で画面をリセットできる

## 動作環境
Web Serial APIに対応するChrome / Edge の最新版(PC版のみ)が必要です。Firefox・Safari、およびモバイル版ブラウザには対応していません。また、`https`または`localhost`でのみ動作します(GitHub Pagesはhttpsのため問題ありません)。

## 注意
- 同時に開けるのは1ポートのみです。別のポートに繋ぎ変える場合は、一度「切断」してから選び直してください
- 大量のデータを長時間受信し続けるとログがブラウザのメモリを消費し続けます。長時間のロギングでは適宜「クリア」するか、ログをダウンロードしてから画面をリセットしてください
