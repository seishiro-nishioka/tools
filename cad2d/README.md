# 簡易2D CAD

点・線分・円を配置し、SolveSpace / Fusion 360のような幾何拘束で正確に組み立てるブラウザツールです。

## 特徴
- インストール不要。ブラウザで開くだけで使えます
- データはサーバーに送信されません。処理はすべて端末内で完結します
- 幾何拘束の計算には、自前の数式ではなく [SolveSpace](https://github.com/solvespace/solvespace) 本家の拘束ソルバー(WebAssembly版、npmパッケージ`slvs`)をそのまま使っています
- ヘッダー左上の「← 一覧」リンクから、いつでもツール一覧ページに戻れます
- 左上の「元に戻す」「やり直す」(Ctrl+Z / Ctrl+Shift+Z)で、図形の作成・削除・移動・拘束の追加解除などモデルへの変更を1操作単位で取り消し・やり直しできます(パン・ズームなどの表示状態は対象外)
- 拘束コマンドの実行順は3通りのいずれでも使えます(必要なオブジェクトの数・組み合わせはコマンドごとに異なります):
  1. **コマンドを先に押してから対象を選ぶ**: 何も選択せずに拘束コマンドを押すと、そのコマンドが「ピック待ち」になる。続けてキャンバス上の図形をクリックしていくと、必要な数・組み合わせが揃った時点で自動的に適用される
  2. **一部だけ選択してからコマンドを押し、残りを選ぶ**: 図形をいくつか選択した状態でコマンドを押すと、その選択を引き継いだままピック待ちになり、残りをクリックして補う
  3. **先に全部選択してからコマンドを押す**: コマンドの条件を満たす数・組み合わせをあらかじめ選択してからコマンドを押すと、即座に適用される
  - ピック待ち中は、押したコマンドのボタンだけが押下状態(青色)のまま有効になり、他のコマンドボタンは一時的に無効化されます。同じボタンをもう一度押す、またはEscキーでピック待ちをキャンセルできます
- 描画ツール:
  - **点**: クリックした位置に点を配置する
  - **線分**: 始点→終点の順にクリックして線分を配置する(既存の点の近くでクリックすると、新しい点を作らずその点に接続する)
  - **円**: 中心→半径を決める位置の順にクリックして円を配置する(中心も既存の点に接続できる)
- 拘束コマンド:
  - **一致**: 2点を同じ位置にする
  - **距離**: 2点間、または点と線分の間の距離を指定値にする
  - **水平**: 線分、または2点を水平にする
  - **鉛直**: 線分、または2点を鉛直にする
  - **平行**: 2本の線分を平行にする
  - **垂直**: 2本の線分を直交させる
  - **等しい**: 2本の線分の長さ、または2つの円の直径を揃える
  - **接する**: 円と円、または円と線分を接させる
  - **直径**: 円の直径を指定値にする
  - **固定**: 選択した図形の基準点(点そのもの、線分の両端、円の中心)のドラッグ移動を禁止/許可する
  - **構築線**: 選択した線分・円を補助図形(破線表示、拘束の対象にはなるが見た目上の目印用)に切り替える
  - **削除**: 選択した図形を削除する(点を削除すると、それを参照する線分・円・拘束も連動して削除されます)
- 拘束された図形は、参照先の図形を動かしたり値を変えたりすると自動的に追従して再計算されます
- 直径の表示切り替え、グリッド表示、ズーム・パン、全体表示に対応

## 使い方
1. 左の描画ツール(点・線分・円)でキャンバス上をクリックし、図形を配置する
2. 拘束をかけたい図形を先に選択してから「拘束」コマンドを押すか、先にコマンドを押してからキャンバス上で対象をクリックしていく(上記「拘束コマンドの実行順」参照)
3. 距離・直径コマンドを使う場合は、コマンドを押す前に左の「値(mm)」欄に数値を入力しておく
4. 固定・拘束されていない点は、「選択・移動」ツールでそのままドラッグして移動できる(ドラッグ中、他の拘束を満たしながらリアルタイムに再計算されます)

## 拘束の計算について
- 持続的な1つのスケッチを編集し続けるのではなく、図形・拘束を変更するたびに、このツールのデータモデル(点・線分・円・拘束の配列)から[SolveSpace](https://github.com/solvespace/solvespace)本家のスケッチを毎回丸ごと再構築して1回solveする方式にしています(この規模の図形数であれば十分高速です)
- SolveSpaceの`tangent()`拘束は円弧(Arc)専用で、完全な円(Circle)には使えないため、「接する」コマンドは次のように数学的に同値な拘束で表現しています(実機検証済み):
  - 円どうし: 中心点どうしの距離 = 半径の和(外接)
  - 円と線分: 円の中心から線分までの距離 = 半径
