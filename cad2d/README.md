# 簡易2D CAD(円の外接配置)

円を描いて、他の円との間に拘束をかけながら正確に配置していくブラウザツールです。SolveSpace / Fusion 360のような「先に図形を選択してから、拘束コマンドを適用する」という操作体系を採用しています。

## 特徴
- インストール不要。ブラウザで開くだけで使えます
- データはサーバーに送信されません。処理はすべて端末内で完結します
- **SolveSpaceと同様の操作体系**: 図形(円)をクリック(Shiftキーで複数選択)してから、左の「拘束」コマンドを押すと、選択内容に適用されます。最後に選んだ円が、他の選択円を基準に拘束されます
- 拘束コマンド:
  - **外接**: 選択した円(2〜3個)のうち最後の円を、残りの円すべてに外接させる(円を1個ずつ外接させながら、円周上に複数配置していく用途にも使えます)
  - **同心**: 2個選択し、最後の円をもう一方と同じ中心にする
  - **距離**: 2個選択し、最後の円をもう一方から指定した中心間距離に配置する
  - **等しい直径**: 2個以上選択した円の直径を揃え、以後も連動させる(どれか1つの直径を変えると全員が追従します)
  - **固定**: 選択した円のドラッグ移動を禁止/許可する(基準にしたい円を動かなくする)
  - **構築線**: 選択した円を、補助円(破線表示)に切り替える
  - **削除**: 選択した円をまとめて削除する
- 拘束をかけた円は、参照先の円の直径や位置を変えると自動的に追従して再計算されます
- 直径の表示切り替え、グリッド表示、ズーム・パン、全体表示に対応

## 使い方
1. 左の「円を描く」ツールでキャンバス上をクリックし、円を配置する(直径は左の入力欄で指定してから配置、または配置後に右のインスペクタで編集)
2. 「選択・移動」ツールに戻り、拘束したい円をクリック(複数選択はShift+クリック)
3. 左の「拘束」コマンド(外接・同心・距離・等しい直径など)をクリックすると、選択内容に適用される(最後に選んだ円が拘束される側になります)
4. 選択内容がコマンドの条件を満たさない場合、そのコマンドのボタンは自動的に無効(グレーアウト)になります
5. 拘束のない円は、「選択・移動」ツールでそのままドラッグして移動できます(固定した円・拘束された円は直接ドラッグできません)

## 外接配置の計算について
- 拘束の計算には、自前の数式ではなく [SolveSpace](https://github.com/solvespace/solvespace) 本家の幾何拘束ソルバー(WebAssembly版、npmパッケージ`slvs`)をそのまま使っています。円を1つずつ「動かさない円+新しい円」という最小のスケッチに組み立てて都度solveSketch()で解く方式です
- SolveSpaceの`tangent()`拘束は円弧(Arc)専用で、完全な円(Circle)どうしの外接には使えないため、「中心点どうしの距離 = 半径の和」という点-点距離拘束(`distance()`)で外接を表現しています(数学的に外接と同値であることを確認済み)
- 円2つに外接させる場合、数学的に解が2つ(上下または左右対称)存在することがあります。このツールでは、操作直前のその円の位置に近い方の解にソルバーが収束するようにしています
