# 簡易2D CAD(円の外接配置)

円を描いて、他の円に「外接」する拘束をかけながら正確に配置していくブラウザツールです。Fusion 360などの拘束ベーススケッチと似た操作感を、円の外接配置という用途に絞って実現します。

## 特徴
- インストール不要。ブラウザで開くだけで使えます
- データはサーバーに送信されません。処理はすべて端末内で完結します
- 円を描いて直径を指定し、他の円に外接させて正確に配置できます
  - **外接(1円に)**: 選んだ円を、指定した1つの円にちょうど外接する位置へスナップさせる
  - **外接(2円に)**: 選んだ円を、指定した2つの円の両方にちょうど外接する位置へスナップさせる(円周上に複数の円を順番に外接配置していく用途向け)
- 拘束をかけた円は、参照先の円の直径や位置を変えると自動的に追従して再計算されます(関連する円を作成順に1パスで解く方式。Fusionのような汎用の反復拘束ソルバーではなく、各拘束を閉じた式で直接解いています)
- 構築線(補助円)の切り替えに対応。配置の基準にするだけの円を、実体のない破線の補助円として区別できます
- 直径の表示切り替え、グリッド表示、ズーム・パン、全体表示に対応

## 使い方
1. 左の「円を描く」ツールでキャンバス上をクリックし、基準にしたい円を配置する(直径は左の入力欄で指定)
2. 必要なら「構築線切替」ツールでその円をクリックし、補助円(破線)にする
3. 新しい円を「円を描く」で、だいたいの位置に仮置きする
4. 「外接(1円に)」ツールで、①仮置きした円 → ②外接させたい相手の円、の順にクリックすると、ちょうど外接する位置へスナップする
5. 3つ目以降の円を円周上に並べたい場合は「外接(2円に)」ツールで、①新しい円 → ②基準円 → ③直前に配置した円、の順にクリックすると、両方に外接する位置へスナップする(これを繰り返すと、円周上に複数の円を外接配置できます)
6. 円を選択すると右側に直径・中心座標・拘束の状態が表示され、直径はその場で編集できます(拘束されている円は自動で追従します)
7. 「選択・移動」ツールで、拘束のない円は自由にドラッグして移動できます

## 外接配置の計算について
- 拘束の計算には、自前の数式ではなく [SolveSpace](https://github.com/solvespace/solvespace) 本家の幾何拘束ソルバー(WebAssembly版、npmパッケージ`slvs`)をそのまま使っています。円を1つずつ「動かさない円+新しい円」という最小のスケッチに組み立てて都度solveSketch()で解く方式です
- SolveSpaceの`tangent()`拘束は円弧(Arc)専用で、完全な円(Circle)どうしの外接には使えないため、「中心点どうしの距離 = 半径の和」という点-点距離拘束(`distance()`)で外接を表現しています(数学的に外接と同値であることを確認済み)
- 円2つに外接させる場合、数学的に解が2つ(上下または左右対称)存在することがあります。このツールでは、操作直前のその円の位置に近い方の解にソルバーが収束するようにしています
